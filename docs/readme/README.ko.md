# 안녕하세요, Bum-Boo예요

[English](../../README.md) | [한국어](README.ko.md)

코드를 몰라도 AI와 로봇, 내 컴퓨터로 실제 일을 해낼 수 있게 도와주는 도구를 만들어요.
대부분 내 컴퓨터에서 돌아가고, 무언가 바꾸기 전에 먼저 물어봐요.

## 쏙 (ssok)

<a href="https://bum-boo.github.io/ssok/"><img src="../../assets/projects/ssok.webp" width="100%" alt="쏙 작업 화면. 빔과 서보로 조립한 인간형 로봇, 왼쪽에 부품 목록, 오른쪽에 서보 프로그램" /></a>

부품을 끼워 로봇을 만들고 서보를 연결한 다음, 코드 몇 줄(또는 블록)을 짜서 실행해 보세요.
Godot로 만든 로봇 공작실이에요. 브라우저에서 바로 열려요.

## AI 에이전트

- [**kakaotalk-local-mcp**](https://github.com/Bum-Boo/kakaotalk-local-mcp): PC 카카오톡을 Claude나 Codex에 연결해요. 허락한 방만 다루고, 답장은 내가 승인해야 보내져요.
- [**agent-change-gate**](https://github.com/Bum-Boo/agent-change-gate): 에이전트가 고칠 내용을 제안하면 바뀌는 부분을 먼저 보고 승인하는 옵시디언 플러그인이에요.
- [**hermes-comfyui-maker**](https://github.com/Bum-Boo/hermes-comfyui-maker): 텔레그램이나 디스코드에서 Hermes Agent로 ComfyUI 이미지 작업을 돌려요.
- [**hermes-desktop-korean**](https://github.com/Bum-Boo/hermes-desktop-korean): Hermes Desktop 한국어 번역이에요.
- [**Vaultwright**](https://github.com/Bum-Boo/Vaultwright): Codex가 옵시디언 볼트를 살펴보되 기존 노트는 건드리지 않게 해요.
- [**hermes-skill-library**](https://github.com/Bum-Boo/hermes-skill-library): Hermes Agent용 스킬을 쓰임새별로 모았어요.

## 집과 리눅스

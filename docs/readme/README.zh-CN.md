# Bum-Boo

> 构建 local-first AI Agent、审批式自动化和实用的 Windows 工作流工具。

[Overview](../../README.md) | [English](README.en.md) | [한국어](README.ko.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md)

我构建让用户在使用 AI 时仍能保有可见性、控制权和数据所有权的软件。目前主要关注 Hermes Agent 扩展、先审核后写入的工作流、local-first 自动化和 Windows 实用工具。

## 代表项目

- [BIGLOADER with AI Agent](https://github.com/Bum-Boo/BIGLOADER-with-Ai-agent) — Windows Instagram 收集器、本地媒体管理器和 Hermes-friendly CLI。
- [Hermes Skill Library](https://github.com/Bum-Boo/hermes-skill-library) — 面向实际 Hermes 工作流的可复用技能库。
- [Agent Change Gate](https://github.com/Bum-Boo/agent-change-gate) — 对限定范围的 Obsidian 修改执行先审核后写入。
- [Hermes Desktop Korean](https://github.com/Bum-Boo/hermes-desktop-korean) — 包含自动覆盖率和类型验证的完整韩语本地化。
- [BBCC](https://github.com/Bum-Boo/BBCC) — 面向创作和媒体控制的 Windows 控制器快捷键映射工具。
- [BTS Sec](https://github.com/Bum-Boo/BTS_sec) — 面向已授权项目的防御性审计工具包。

## 设计原则

- 默认将私有工作流数据保留在本地。
- 在持久写入前先检查并提出建议。
- 自动化只在用户明确批准的边界内运行。
- 优先使用备份、分支、草稿和清晰的回滚路径。
- 诚实标注实验状态和当前限制。

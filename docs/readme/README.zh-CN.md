我正在实践 **AI 体验设计**：让 AI 在开发者工具之外也能发挥作用，同时让使用者能够理解它的状态、范围和后果。

我的工作游走于设计、认知、技术、媒体和日常习惯之间。桌面实用工具、Agent 工作流、本地档案库、控制器或小型界面，都可以成为让普通体验更轻松、更有助益的方式。

## 实验室

我通常从容易被忽视的摩擦开始：无法审核的修改、变得难以管理的文件夹、语言障碍，或本应只需按一下按钮的重复操作。

> **反复追问的问题：** AI 如何在不抹去人的选择的前提下，帮助人们感到自己更有能力？

<img src="../../assets/research-os.svg" width="100%" alt="从日常摩擦走向有效改变的研究过程" />

## 当前研究方向

- 面向没有开发背景人群的 AI 体验设计
- 认知、发展、学习、注意力，以及工具重塑行为的方式
- 在写入前审核、让人的决策保持可见的 Agent
- 支持私密、持久、可逆工作的本地优先系统
- 用富有趣味的界面降低严肃工具的距离感
- 不受固定媒介或产品类别限制的跨学科实验

### 当前假设

- 当 AI 的状态、范围和不确定性保持可见时，它会更加有用。
- 非开发者需要的不是简化版智能，而是更好的交互约定。
- 富有趣味的界面可以在不掩盖操作严肃性的同时减轻恐惧。
- 本地优先架构不仅是隐私基础设施，也是体验设计的选择。

### 富有成效的张力

| 张力 | 我正在探索的内容 |
|---|---|
| 自动化 ↔ 主体性 | 在控制变得不可见之前，应该有多少事情自动发生？ |
| 智能 ↔ 可理解性 | 强大的系统能否仍用符合人类尺度的语言解释自己正在做什么？ |
| 实用 ↔ 愉悦 | 严肃的工作流能否富有趣味而不让人分心？ |
| 广度 ↔ 连贯性 | 开放式探索如何仍能产出聚焦、实用的成果？ |

### 未完成的问题

- 当对话只是诸多材料之一时，AI 界面会是什么样子？
- 工具如何支持认知成长，而不是不加区分地替代人的努力？
- 哪些日常挫折小到容易忽略，却重要到值得重新设计？

## 工作原则

- **本地优先。** 让个人工作流数据留在其所有者身边。
- **写入前审核。** 让修改在持久化之前保持可见。
- **可逆设计。** 优先使用草稿、分支、备份和清晰的退出路径。
- **开放式研究。** 让问题决定学科与媒介。
- **日常愉悦。** 严肃的技术也可以富有趣味并有人情味。

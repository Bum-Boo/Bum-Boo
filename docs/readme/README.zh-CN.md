# Bum-Boo

> 专注于本地优先的 AI Agent、审批式自动化，以及真正服务于工作流程的 Windows 工具。

[概览](../../README.md) | [English](README.en.md) | [한국어](README.ko.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md)

我希望人们在使用 AI 的同时，仍然保有对数据的所有权和对操作过程的控制权。目前主要开发 Hermes Agent 扩展、写入前审核工作流、本地优先的自动化方案，以及面向 Windows 的实用工具。

## 主要项目

- [BIGLOADER with AI Agent](https://github.com/Bum-Boo/BIGLOADER-with-Ai-agent) — 用于收集 Instagram 帖子和管理本地媒体的 Windows 工具，并提供便于 Hermes 调用的命令行接口。
- [Hermes Skill Library](https://github.com/Bum-Boo/hermes-skill-library) — 汇集可在实际 Hermes 工作流中复用的技能与操作方案。
- [Agent Change Gate](https://github.com/Bum-Boo/agent-change-gate) — 在写入 Obsidian 前先展示修改内容，只执行用户批准范围内的变更。
- [Hermes Desktop Korean](https://github.com/Bum-Boo/hermes-desktop-korean) — Hermes Desktop 的完整韩语本地化，并配有自动覆盖检查和类型验证。
- [BBCC](https://github.com/Bum-Boo/BBCC) — 面向创作流程和媒体控制的 Windows 控制器快捷键工具。
- [BTS Sec](https://github.com/Bum-Boo/BTS_sec) — 用于已获授权的 Web 与本地项目的防御性审计工具包。

## 开发原则

- 除非用户明确选择，否则个人数据和工作数据默认保留在本地。
- 在执行持久化修改前，先提供调查结果和修改建议。
- 将自动化限制在用户明确批准的文件夹、目标、账号和任务队列内。
- 优先采用备份、分支、草稿和清晰的恢复路径。
- 如实说明实验性功能、平台限制和尚未完成的部分。

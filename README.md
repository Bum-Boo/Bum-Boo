# Hi, I'm Bum-Boo

[English](README.md) | [한국어](docs/readme/README.ko.md)

I make tools that let people who don't write code get real work done with AI, robots and their own computer.
Most of them run on your machine and ask before they change anything.

## ssok

<a href="https://bum-boo.github.io/ssok/"><img src="assets/projects/ssok.webp" width="100%" alt="ssok workshop: a humanoid robot built from beams and servos, with the parts library on the left and a servo program on the right" /></a>

Snap parts together, wire the servos, write a few lines of code (or use blocks) and press Run.
A robotics workshop for learning, made in Godot. It runs in the browser.

**[Play in the browser](https://bum-boo.github.io/ssok/)** · [Source](https://github.com/Bum-Boo/ssok) · [Download v0.2.0](https://github.com/Bum-Boo/ssok/releases/tag/v0.2.0)

## AI agents

- [**kakaotalk-local-mcp**](https://github.com/Bum-Boo/kakaotalk-local-mcp): connect KakaoTalk for Windows to Claude or Codex. Only the rooms you allow, and replies wait for your approval.
- [**agent-change-gate**](https://github.com/Bum-Boo/agent-change-gate): an Obsidian plugin where the agent proposes an edit and you see the diff before it is written.
- [**hermes-comfyui-maker**](https://github.com/Bum-Boo/hermes-comfyui-maker): run ComfyUI image workflows from Telegram or Discord through Hermes Agent.
- [**hermes-desktop-korean**](https://github.com/Bum-Boo/hermes-desktop-korean): Korean translation for Hermes Desktop.
- [**Vaultwright**](https://github.com/Bum-Boo/Vaultwright): lets Codex review an Obsidian vault without editing your notes.
- [**hermes-skill-library**](https://github.com/Bum-Boo/hermes-skill-library): a curated set of skills for Hermes Agent, grouped by purpose.

## Home and Linux

- [**calmhome-sensor**](https://github.com/Bum-Boo/calmhome-sensor): know whether someone is in the room, or hasn't moved for a while, using radar instead of cameras. Home Assistant + ESPHome.
- [**frieren-os**](https://github.com/Bum-Boo/frieren-os): my Arch Linux + KDE Plasma desktop, built as a bootable ISO.
